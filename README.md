# 对象级视频异常检测：8B与27B四层级实验报告

**汇报周期：2026年10月20日—26日**

**评估对象：Qwen3-VL-8B-Instruct与27B接口模型**

**目标：依次判断能否检出异常、识别正确事件及类别、找到核心对象、定位对象所在空间。**

> 统一以167段视觉支持异常的片段为分母，27B的四层级通过率为80.2%、68.9%、15.0%、4.2%；8B为70.1%、66.5%、6.6%、1.8%。两模型的主要瓶颈均发生在对象身份、异常归属及角色，其次是空间位置。本轮未评估完整异常起止时间，也不将这些结果称为独立人工真值下的整体准确率。

## 1. 本期实验与评估范围

本期从上周的压缩探索转向核查不压缩基线：在10 FPS源抽帧及六大类异常规则下，对同一视频逐级判断“异常是否存在、发生了什么、谁参与异常、对象在哪里”。本报告整理已有实验与视觉复核，不新增模型调用，不修改原始响应。

| 项目 | 范围与口径 |
|---|---|
| 原实验计划 | 232段视频 |
| 本次固定对照范围 | 同一189段，双方均有终态记录，并已完成逐段视觉复核 |
| 复核支持异常 | 167段，作为四级主表的统一分母 |
| 复核支持正常 | 3段，只用于单列观察正常片段误报 |
| 必要场景政策不足 | 19段，不强行归为正常或异常 |
| 未纳入本轮四级裁决 | 其余43段，不补入本报告的评估分母 |

这里的参考是**Codex原生视觉裁决，并非独立人工真值**。复核依据原片画面与冻结场景规则，不将旧异常候选直接当作正确答案；`human_verified=false`，`eligible_for_formal_supervised_training=false`。

### 模型与输入设置

| 项目 | 8B | 27B |
|---|---|---|
| 模型标识 | `Qwen/Qwen3-VL-8B-Instruct` | 接口别名`Qwen3.8-27B` |
| 权重核实 | 固定revision：`0c351dd01ed87e9c1b53cbc748cba10e6187ff3b` | 服务端权重及revision未验证 |
| 视频输入 | 10 FPS最近原生帧采样，并加入唯一末帧 | 同源采样帧通过2 FPS无损慢放载体传送，附原片时间映射 |
| 服务端实际采样 | 依据保存的8B输入及运行记录 | 缺少逐帧消费回执，不能保证服务端实际使用全部源采样帧 |
| 输出上限 | 固定189段快照使用8192 tokens | 全232段中26段使用4096、206段使用8192；已完成响应保留，不重新推理 |

| 语义重试 | 不因漏检或回答不理想而重试 | 同左 |

六大类规则为：**G01人际攻击或强取、G02物品破坏或危险抛掷、G03火烟及危险操作、G04事故或危险状态、G05交通及骑行危险、G06区域违规及占用**。区域类事件须有输入中启用的场景政策，不能仅凭场景名称或人物靠近判异常。

## 2. 四个层级如何定义

| 层级 | 通过标准 |
|---|---|
| L1：异常检出 | 在视觉支持异常的片段中，报告存在有效异常主张；类别或后级定位错误不自动抹掉可读的异常主张。 |
| L2：正确事件及大类 | L1通过，且至少一项真实发生的异常事件及其G01—G06大类正确；只有类码相同、动作描述不成立，不算通过。 |
| L3：核心对象与角色 | 前两级通过，且所有核心异常对象的身份、异常归属与角色正确；不漏核心对象、不虚构主体、不互换身份或重复同一实体。 |
| L4：空间九宫格 | 对象级通过，每个核心异常对象至少有可核查位置，且输出标注帧的框中心九宫格均正确。 |

四级采用**累计通过**：L3不是只要描述对某一个人就通过，L4也不能在对象身份错误时单独算正确。空间格号按完整原画面从左上到右下排列为1—9，预测位置按归一化边框的中心落格核查。

## 3. 主结果：统一分母167段支持异常

8B的27段不可读异常响应保留在分母中，不当作正常，也不从主表中删去。

| 层级 | 8B | 27B | 27B减8B |
|---|---:|---:|---:|
| L1：检出异常 | 117/167（70.1%） | 134/167（80.2%） | +10.2个百分点 |
| L2：正确事件及大类 | 111/167（66.5%） | 115/167（68.9%） | +2.4个百分点 |
| L3：核心对象与角色正确 | 11/167（6.6%） | 25/167（15.0%） | +8.4个百分点 |
| L4：异常对象中心九宫格正确 | 3/167（1.8%） | 7/167（4.2%） | +2.4个百分点 |

**结果解读：**在这组统一分母下，27B四级均高于8B，但“能报出异常”与“能定位所有正确对象”之间仍存在很大差距。27B检出134段异常，最终只有7段同时通过对象与空间核查；8B对应为117段和3段。

这些比例是该异常组的逐级通过率，不是包含一般正常场景的整体分类准确率，也不是对象检测AP、视频AUC或时空AP。

## 4. 失败主要发生在哪一级

以下按**每段首次失败的位置**分组，互不重复；每个模型一列之和均为167。对象级失败的片段不会再重复归为空间失败。

| 首次失败或最终通过 | 8B（段） | 27B（段） |
|---|---:|---:|
| 输出不可读 | 27 | 0 |
| 未检出异常 | 23 | 33 |
| 事件或大类不正确 | 6 | 19 |
| 核心对象或角色不正确 | 100 | 90 |
| 对象已正确，但中心九宫格不正确 | 8 | 18 |
| 四级全部通过 | 3 | 7 |

### 以前一级通过段数为分母

| 层级衔接 | 8B条件通过率 | 27B条件通过率 |
|---|---:|---:|
| 检出异常 → 正确事件及大类 | 111/117（94.9%） | 115/134（85.8%） |
| 正确事件及大类 → 核心对象与角色正确 | 11/111（9.9%） | 25/115（21.7%） |
| 核心对象正确 → 空间九宫格正确 | 3/11（27.3%） | 7/25（28.0%） |

**最大损失发生在对象级：**8B已正确识别事件与大类的111段中，有100段未通过全部核心对象及角色核查；27B的115段中也有90段未通过。

**空间问题也仍然明显：**即使对象已经正确，两个模型都只有约28%进一步通过位置核查。因此，不能将失败全部归因于对象在移动；还需分开处理漏对象、身份错认、角色错配、异常归属及框中心错位。

## 5. 排除输出不可读后，比较结论是否变化

在167段支持异常的片段中，双方输出均可读的共同子集为140段。该表用于观察输出可用性对主表的影响，**不能替代167段主表**。

| 层级 | 8B | 27B |
|---|---:|---:|
| L1：检出异常 | 117/140（83.6%） | 111/140（79.3%） |
| L2：正确事件及大类 | 111/140（79.3%） | 98/140（70.0%） |
| L3：核心对象与角色正确 | 11/140（7.9%） | 21/140（15.0%） |
| L4：异常对象中心九宫格正确 | 3/140（2.1%） | 6/140（4.3%） |

在这个筛选后的同片子集中，8B前两级高于27B，27B对象级和空间级仍较高。这说明主表差异包含输出可用性的影响，不能简单解释为参数更多就一定在所有方面更好；也不能利用筛选后的子集宣称8B整体更好。

## 6. 输出格式与异常识别分别统计

| 同一189段的输出状态 | 8B | 27B |
|---|---:|---:|
| 可用于逐级语义复核的响应 | 158 | 189 |
| 不可读响应 | 31 | 0 |
| 严格schema及关系契约通过 | 136 | 187 |
| 3段支持正常中的正确判正常 | 0 | 0 |
| 3段支持正常中的误报 | 3 | 3 |

“可读响应”和“严格契约通过”不是同一个口径。部分回答存在对象字段、关系或位置契约问题，但异常主张仍可读；本轮逐级核查这些错误，不用后级格式问题自动否定前级异常识别。

3段正常参考规模很小，且来自经过选择的复核队列，不能据此估计一般场景的误报率。19段必要政策不足也没有被当作正常对照。

## 7. 一个具体案例：事件检出正确，仍可能对象或位置失败

**案例002：广场上的电动两轮车。**已有视觉复核查看全36帧及原生关键帧，记录深灰短袖男子骑蓝色电动两轮车从右向左横穿主广场铺装；本片启用广场禁骑研究政策，支持G06。

- **8B：**能报出广场骑行异常，事件与大类通过；但把男子的`kind`写为`vehicle`，没有独立覆盖车辆对象，并额外列出证据不支持的G05事件，未通过严格对象级。
- **27B：**骑手与车辆的身份、`driver`及`state_subject`角色正确；但F010两个框中心落在第5格，复核记录的实际对象中心在第6格，F015的框也偏左，因此对象级通过、空间级失败。

该案例说明，**识别行为、找到正确主体与给出正确位置是三个不同环节**，不能只凭存在边框就认为对象定位正确。本报告引用已有裁决，本次未重新进行视觉判定。

## 8. 本轮结论与限制

1. **异常识别已有一定能力，对象级空间定位仍弱。**在统一167段口径下，27B的异常检出为80.2%，但核心对象与角色通过仅15.0%，完整通过空间九宫格仅4.2%；8B对应为70.1%、6.6%和1.8%。
2. **时间定位尚无结果。**本轮F编号和时间仅用于回到对应原片帧，没有评估完整异常起止区间或temporal IoU。空间九宫格通过也不能推出时间定位正确。
3. **空间指标较粗。**没有精确像素参考框或掩码真值，不报告bbox IoU、掩码J&F或时空AP；本轮也没有验证完整对象轨迹的逐帧精度。
4. **比较存在输入与服务端透明度限制。**27B服务端采样及权重未完全验证，输出上限存在已保留的4096／8192历史版本，因此本实验不是只改变模型参数规模的严格消融。
5. **参考质量边界保持不变。**本轮为Codex原生视觉复核，非独立人工真值；既有失败记录、原始响应、规则版本和历史结果均保留。

## 9. 下一步工作

1. 优先整理已正确识别事件、却未通过对象级的100段8B与90段27B记录，进一步区分漏对象、身份互换、角色错配、虚构主体等问题。
2. 将对象身份与跨帧位置分别评估，使用独立对象／位置参考检查完整轨迹；评估用的描述、框与时间不得作为待测模型输入。
3. 单独定义异常起止标注及时间指标，再开展时间定位实验。当前不以“输出了几个位置帧”代替时空定位成功。

以上为后续计划，本次没有启动新的模型推理或修改已冻结答案。
